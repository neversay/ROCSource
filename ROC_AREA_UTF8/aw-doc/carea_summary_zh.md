# ROC MUD 區域檔 (.are) 格式概述與參考指南

本文件為 **ROC MUD 區域檔 (`.are`)** 格式的完整參考指南，基於 `carea.txt` 文件編譯而成。ROC MUD 是一款基於 Envy/Merc 2.2 架構並由 Neversay 及其他 ROC 開發者進行大量客製化改寫的 MUD 遊戲。

---

## 1. 整體架構與資料型態

區域檔由多個不同的區塊組成，每個區塊以特定的首部標記（如 `#AREA`、`#MOBILES`）開始。區塊必須按照邏輯順序排列（特別注意：`#MATERIAL` 必須在 `#OBJECTS` 之前定義）。檔案最後以 `#$` 標記結束。

### 引擎解析的資料型態：
* **`letter`**: 單一非空白字元。
* **`word`**: 一連串非空白字元，以空白字元（Space、Tab、換行）做結束。
* **`string`**: 一連串非波浪號字元，最後以波浪號 `~` 做結束。可以包含空白、換行與多行文字。
* **`number`**: 整數數值。可以使用位元或運算子 `|` 將多個 flag 串接相加（例如 `1|64` 在引擎讀入後會被相加為 `65`）。部分數值參數可直接接受常數字串（例如使用 `ACT_AGGRESSIVE` 來代替 `32`）。
* **`number as string`**: 本質為整數，但格式上必須加上波浪號 `~` 作為字串表示（例如 `100~`）。
* **`vnum`**: 虛擬編號，用來唯一識別房間、怪物與物品。範圍從 `1` 到 `1,000,000`。通常同一個區域會共用特定範圍的 vnum（例如 `3000` 到 `3399`）。

## 2. 各區塊格式說明

### 2.1 #AREADATA
定義區域的元數據（Metadata）。
* **格式語法**：
  ```text
  #AREADATA
  Name        [字串] 適合等級與有名稱（例如：{ ALL } 史卡拉貝城~）
  Identity    [字串] 區域識別名稱，用於 MobProgs（例如：skarabrae~）
  Builders    [字串] 原始撰寫人~
  Translator  [字串] 翻譯者~
  Modifier    [字串] 改編者~
  VNUMs       [數字] [數字]（OLC 線上編輯所佔的 vnum 範圍起點與終點）
  Security    [數字] 線上修改權限等級（1-9）
  Recall      [數字] 預設 Recall 點的房間 vnum（預設為 3001）
  Death       [數字] 死亡後重生的房間 vnum（選填，若無設定則預設為 Recall 點）
  F_toggle    [數字]（選填）設為 1 時反轉此區域所有房間的 room flag，設為 0 則維持原設定。
  End
  ```

---

### 2.2 #HELPS
定義內置於區域檔中的說明文件。
* **格式語法**：
  ```text
  #HELPS
  [最低等級:數字] [關鍵字:字串]
  [說明內文:字串]
  0 $~  （結束標記）
  ```
  * *註*：如果「最低等級」設定為負數，該關鍵字會有特殊系統用途（例如 `-1` 用於剛連線時的 greeting 畫面）。

---

### 2.3 #MATERIAL
ROC 特有的材質定義區塊。**必須置於 `#OBJECTS` 之前**，以確保物品能正確載入材質屬性。
* **格式語法**：
  ```text
  #MATERIAL
  #[vnum:數字]
  [名稱:字串]
  [中文名稱:字串]
  [未使用:字串]
  [未使用:字串]
  [幫派等級限制:數字] [額外flag:數字] [貼材質幫派花費:數字]
  [命中修正:字串型數字] [傷害修正:字串型數字] [防禦修正:字串型數字] [耐用度:字串型數字]
  [重量加成百分比:數字] [價格加成百分比:數字] [每日維持花費:數字]
  { A [附加效應類型:數字] [附加值:數字] }             （可有多組，影響裝備者屬性）
  { H [魔法編號] [觸發機率百分比] [法術等級] [觸發時機] } （可有多組，隱藏能力：1=裝備時、2=戰鬥時、4=武器攻擊時、8=盾牌阻擋時、16=箭矢擊中時）
  { L [裝備等級限制:數字] }                           （最多1組）
  { P [職業限制參數:數字] }                           （最多1組，可使用ALLOW/DENY二進位值）
  { R [種族限制參數:數字] }                           （最多1組，可使用ALLOW/DENY二進位值）
  { V [適用種族:字串] [命中實值修正] [命中%修正] [傷害實值修正] [傷害%修正] }（可有多組，種族加成修正）
  { F [法術持續狀態:數字/字串] }                        （可有多組，穿戴時賦予的持續魔法效果，如 `F AFF_FLYING`）
  #0    （結束標記）
  ```

---

### 2.4 #MOBILES
定義行動生物（NPC/Monster）。
* **格式語法**：
  ```text
  #MOBILES
  #[vnum:數字]
  [關鍵字列表:字串]
  [簡短敘述(short-description):字串]
  [進房長敘述(long-description):字串]
  [看怪詳細敘述(description):字串]
  [動作參數(act-flags):數字/字串] [狀態參數(affected-flags):數字/字串] [陣營(alignment):數字] S
  [等級] [血量修正] [魔力修正] [命中修正] d [傷害骰修正] + [防禦修正] [存檢修正] d [閃躲修正] + [未使用]
  [攜帶金錢] [未使用]
  [未使用] [預設姿勢] [性別]
  { R [種族名稱:字串] }          （種族名稱，需加波浪號且注意大小寫，如 Dragon~）
  { C [職業類型:數字/字串] }      （職業：0=NORMAL, 1=WARRIOR, 2=MAGE, 4=THIEF, 8=SWORD, 16=SHOT ARROW, 32=BLOODY，可以 | 串接）
  { P [特殊法術反應參數:數字] }    （特殊設定，例如 8 代表 No charm 防止被魅惑）
  { W [技能名稱:字串] [命中率修正百分比] [傷害修正百分比] } （弱點/抗性設定，如 `W magic missile~ 200 300` 代表遭受魔法飛彈攻擊時傷害變 3 倍）
  { S [加強類型] [影響值] }       （提升怪物屬性數值，如 `S 40 5` 增加 5 點魔法潛力）
  { K [可教授技能清單~] }         （怪物可教授的技能，若技能前加 `*` 代表玩家身上必須有同名 qmark 才能學）
  { J [可轉職業清單~] }           （此怪物允許玩家進行轉職的職業類別）
  { A[時間點:數字]               （日常作息/活動行程設定）
    [動作指令1]+[動作指令2]...
    ~                            （多段作息以 `~` 分隔，最後以 `|` 結束）
  }
  #0    （結束標記）
  ```

### 2.5 #MOBPROGS & #ROOMPROGS
將指定 vnum 的怪物或房間，關聯至獨立編寫的觸發腳本檔案（位於 `area/MOBProgs/` 或 `area/ROOMProgs/` 目錄下，副檔名為 `.prg`）。
* **格式語法**：
  ```text
  #MOBPROGS
  M [怪物vnum] [腳本檔名:字串]
  S   （結束標記）
  ```
  ```text
  #ROOMPROGS
  R [房間vnum] [腳本檔名:字串]
  S   （結束標記）
  ```

---

### 2.6 #OBJECTS
定義物品（Equipment/Items）。
* **格式語法**：
  ```text
  #OBJECTS
  #[vnum:數字]
  [關鍵字列表:字串]
  [簡短敘述(short-description):字串]
  [地上長敘述(long-description):字串]
  [動作描述(action-description):字串]
  [物品類型:數字] [額外flag:數字] [裝備部位flag:數字]
  [value-0:字串型數字] [value-1:字串型數字] [value-2:字串型數字] [value-3:字串型數字]
  [重量:數字] [價格:數字] [等級上限限制:數字]（等級限制保護新手裝不被高階玩家濫用）
  { E [關鍵字:字串] [詳細敘述:字串] } （可有多組，看特定部位的額外描述）
  { A [附加類型:數字] [影響值:數字] }  （可有多組，影響裝備者數值）
  { H [魔法編號] [觸發機率] [等級] [觸發時機] } （可有多組，隱藏能力）
  { L [物件限制等級:數字] }         （最多1組，限制此等級上下才能穿）
  { T [有效生存時間:數字] }         （最多1組，經過指定 tick 後消失）
  { C [覆蓋價格:數字] }             （最多1組，通常與基礎價格一致）
  { P [職業限制參數:數字] }         （最多1組， class 限制）
  { R [種族限制參數:數字] }         （最多1組， race 限制）
  { M [觸發事件:0/1] [訊息字串] }     （最多2組，0=穿上時訊息，1=脫下時訊息）
  { X [物品材質名稱:字串] }         （最多1組，指定材質名稱）
  { V [適用種族:字串] [命中實值修正] [命中%修正] [傷害實值修正] [傷害%修正] }（可有多組）
  { F [法術持續狀態:數字/字串] }      （可有多組，穿戴時附予的持續魔法效果）
  { U [替代品vnum:數字] }           （最多1組，設定為獨一無二(Unique)物品，若線上已有則改生成此替代品）
  #0    （結束標記）
  ```

#### 常見物品類型 value[0-3] 設定摘要：
* **01 ITEM_LIGHT (光源)**: `v2` = 持續 ticks (`0` 代表熄滅，`-1` 代表無限)。
* **02 ITEM_SCROLL (捲軸)**: `v0` = 法術等級，`v1` = 封印法術一，`v2` = 封印法術二，`v3` = 封印法術三。
* **03 ITEM_WAND (魔杖) / 04 ITEM_STAFF (法杖)**: `v0` = 法術等級，`v1` = 最大施展次數，`v2` = 剩餘次數，`v3` = 法術名稱。
* **05 ITEM_WEAPON (武器)**:
  * `v0` = 耐用度（`-1` 代表不損壞，或用 `目前值1最大值` 格式（如 `101500`），若生出來就是 100% 則直接填最大值）。
  * `v1` = 最小傷害值，`v2` = 最大傷害值。
  * `v3` = 攻擊類型（例如 `00` 奮力擊打, `01` 銳利切割, `02` 偷偷一戳, `03` 揮舞劈砍, `11` 尖銳刺擊, `14` 射出箭矢）。
* **09 ITEM_ARMOR (防具)**: `v0` = 防禦AC (`0` 為系統自動計算)，`v1` = 被噴酸次數，`v2` = 耐用度。
* **10 ITEM_POTION (藥水) / 26 ITEM_PILL (藥丸)**: `v0` = 法術等級，`v1` = 封印法術一，`v2` = 封印法術二，`v3` = 封印法術三。
* **15 ITEM_CONTAINER (容器)**: `v0` = 可承載總重量，`v1` = 旗標 (`1` 可關上, `2` 無法撬開, `4` 關上的, `8` 鎖住的)，`v2` = 鑰匙 vnum，`v3` = 減重袋/不計件數設定（正數為減重%，負數為減物品數）。
* **17 ITEM_DRINK_CON (液體容器)**: `v0` = 總容量，`v1` = 目前盛裝量，`v2` = 液體種類 (0=水, 1=啤酒, 2=葡萄酒, 13=血 等)，`v3` = 是否有毒 (`非0` 代表有毒)。
* **19 ITEM_FOOD (食物)**: `v0` = 食物狀態，`v2` = 存在時間，`v3` = 是否有毒 (`非0` 代表有毒)。
* **27 ITEM_ARROW (箭矢)**: `v0` = 數量，`v1` = 最小傷害修正，`v2` = 最大傷害修正，`v3` = 額外傷害。

### 2.7 #ROOMS
定義環境空間（房間）。
* **格式語法**：
  ```text
  #ROOMS
  #[vnum:數字]
  [房間名稱:字串]
  [房間描述:字串]
  [區域編號:數字] [房間flags:數字/字串] [地形類型:數字/字串]
  { D[方向編號:數字]                  （出口設定：0=北, 1=東, 2=南, 3=西, 4=上, 5=下）
    [出口描述:字串]
    [開關門關鍵字:字串]
    [鎖類型flag:數字] [鎖匙vnum:數字] [通往房間vnum:數字]（鎖旗標：1=有門, 2=關上, 4=鎖上, 8=被撞開, 16=防撞, 32=防撬, 64=防穿透）
  }
  { E [關鍵字列表:字串] [詳細描述:字串] } （可有多組，房間細部描述）
  S     （單一房間結束標記）
  #0    （整個房間區塊結束標記）
  ```

### 2.8 #RESETS
指定區域重置或載入時的重置動作指令。重置通常在區域內無玩家時每 3 分鐘發生一次，有玩家時每 15 分鐘發生一次。
* **格式語法**：
  * **註解**：`* [註解文字]`
  * **載入怪物**：`M 0 [怪物vnum] [最大上限] [房間vnum]`（在指定房間載入怪物，不超過世界總上限）
  * **載入物品到地上**：`O 0 [物品vnum] 0 [房間vnum]`（在房間地上載入物品）
  * **載入到容器中**：`P 0 [物品vnum] 0 [容器vnum]`（將物品載入至最近載入的容器物品中）
  * **給予怪物物品**：`G 0 [物品vnum] 0`（給予最近載入的怪物物品）
  * **讓怪物裝備物品**：`E 0 [物品vnum] 0 [裝備部位編號]`（讓最近載入的怪物裝備物品至指定部位）
  * **設定門狀態**：`D 0 [房間vnum] [出口方向] [狀態值]`（重置門狀態：0=開啟且未鎖, 1=關閉且未鎖, 2=關閉且鎖上）
  * **打亂出口(迷宮)**：`R 0 [房間vnum] [方向上限值]`（將房間出口隨機打亂，用於隨機迷宮）
  * **怪物結伴**：`F [跟隨者vnum] [房間vnum] [是否保護護衛] [隊長vnum]`（將怪物組成隊伍）
  * **結束標記**：`S`

#### 怪物裝備部位編號 (`裝備部位編號` 對照表)：
* `-1` 純攜帶 | `0` 光源 | `1` 左手指 | `2` 右手指 | `3` 脖子1 | `4` 脖子2 | `5` 身體 | `6` 頭部 | `7` 腿部 | `8` 腳部 | `9` 雙手 | `10` 手臂 | `11` 盾牌 | `12` 披掛 | `13` 腰部 | `14` 左手腕 | `15` 右手腕 | `16` 主要武器 | `17` 手持 | `18` 次要武器 | `19` 雙手持武器 | `20` 弓箭 | `22` 第三手指(眼魔專用) | `23` 第四手指(眼魔專用)

### 2.9 #SHOPS
定義商店交易 NPC。
* **格式語法**：
  ```text
  #SHOPS
  [老闆怪物vnum] [交易類型0] [交易類型1] [交易類型2] [交易類型3] [交易類型4] [買入Markup%] [賣出Markdown%] [營業起點小時] [營業終點小時]
  0     （結束標記）
  ```
  * `老闆怪物vnum`：擔任商店老闆的怪物。該怪物必須載入至特定房間且建議設定 `SENTINEL` flag。
  * `交易類型 0~4`：老闆願意收購的物品種類代碼（0 代表不用）。
  * `買入Markup%`：玩家向老闆買東西時的價格加成百分比（100 為原價，150 為加成 50%）。
  * `賣出Markdown%`：玩家賣東西給老闆時的收購價格折損百分比（100 為原價，75 為折損 25%）。
  * `營業起點/終點小時`：24小時制營業時間（如 `0 23` 代表24小時營業）。

---

### 2.10 #SPECIALS
將特定的 C 語言特殊動作行為函數，指派給指定的怪物（NPC）。
* **格式語法**：
  ```text
  #SPECIALS
  M [怪物vnum] [特殊函數名稱:單字]
  S   （結束標記）
  ```
  * 例如：`M 3011 spec_executioner` 將 3011 怪物設定為執法者 AI。

### 2.11 #$
整個區域檔的絕對結束標記。
